Gestionar la tienda

Desde aquí podéis añadir, cambiar y borrar productos, subir sus fotos y poner el enlace de Wallapop. Al guardar, la web se actualiza sola en uno o dos minutos.

Para guardar hace falta una clave de acceso de GitHub. Solo se crea una vez:

  1. Entrad en GitHub con vuestra cuenta y abrid esta página para crear una clave.
  2. En Token name poned «Tienda N.A.N.A.» y en Expiration elegid hasta cuándo servirá (por ejemplo, un año).
  3. En Resource owner elegid Nana-Asoc. En Repository access marcad Only select repositories y elegid WebNana.
  4. En Permissions → Repository permissions → Contents elegid Read and write.
  5. Pulsad Generate token, copiad la clave (empieza por github_pat_) y pegadla aquí.
