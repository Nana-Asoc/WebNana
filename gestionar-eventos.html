Gestionar los eventos

Desde aquí podéis añadir, cambiar y borrar los eventos de la web y subir su foto. Al guardar, la web se actualiza sola en uno o dos minutos, en castellano y en catalán.

Se usa la misma clave de acceso de GitHub que para gestionar la tienda. Si ya la tenéis guardada en este dispositivo, se conecta sola. Si no, se crea una vez:

  1. Entrad en GitHub con vuestra cuenta y abrid esta página para crear una clave.
  2. En Token name poned «Web N.A.N.A.» y en Expiration elegid hasta cuándo servirá (por ejemplo, un año).
  3. En Resource owner elegid Nana-Asoc. En Repository access marcad Only select repositories y elegid WebNana.
  4. En Permissions → Repository permissions → Contents elegid Read and write.
  5. Pulsad Generate token, copiad la clave (empieza por github_pat_) y pegadla aquí.

Eventos
